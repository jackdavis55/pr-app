# PR Club

A public demo of a personal records dashboard built with Next.js. No account or sign-in is required. Exercise changes are saved in the current browser with local storage.

## Run locally

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Browse the sample lifts, or add, edit, and delete records. Changes persist in that browser and are not shared with other visitors or devices.
